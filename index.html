閾値感度ラボ

標本数、上限頻度、有意水準、比較数を変え、厳密二項上側確率から得られる基準値を比較します。通常分析とは独立した学習用の試算です。

厳密値とモンテカルロ推定

基準行のn、p、kを使い、単一の二項上側確率を疑似乱数で推定して厳密値と比べます。

試行回数とシードを選び、「推定する」を押してください。

この推定は基準行における1つの二項上側確率だけを扱います。5文字全体や26シフト全体の誤判定率、復号の正しさは推定しません。

設定を変えた結果は教材上の比較です。入力したpやαが対象文章に適切であることや、暗号文の正解を示すものではありません。

希少文字チェック（J, K, Q, X, Z）

各シフトで5文字を同時に調べます。厳密二項上側確率にBonferroni補正を適用し、基準以上の文字があるシフトを「要確認」として分けます。

チェック基準の計算

文字数 n 0
上限頻度 p 0.00772
5文字全体 α 0.003
基準 k -
k = min { k : P(X ≥ k) ≤ α / 5 }, X ~ Bin(n, p)

p = 0.00772、α = 0.003。k個以上を観測した文字がある場合に「基準超過」と表示します。

この計算は、各文字が独立に同じ確率で現れるという単純化した英語モデルを使う教育用チェックです。26シフト全体の誤判定率や、文章の自然さ・意味・暗号方式は判定しません。

希少文字チェックの計算方法

何を調べるか

J, K, Q, X, Zの各出現回数を、成功確率p = 0.00772の二項分布と比較します。このpは5文字のうち最も高い基準頻度を共通に使うため、単純な上限モデルです。

厳密二項上側確率

正規近似の3σ式ではなく、P(X ≥ k)を二項分布から直接計算します。標準偏差は√(np(1-p))ですが、基準値の算出に正規近似は使いません。

5文字の多重比較

5文字のいずれかが偶然基準を超える影響を抑えるため、全体のα = 0.003を5で割るBonferroni補正を使います。これは各シフト内の5比較に対する上限であり、26シフト全体の信頼区間ではありません。

読み方と限界

基準超過は、そのシフトを捨てる命令ではなく再確認の印です。言語、文体、固有名詞、短い入力、文字の依存関係によって頻度は変わります。χ²順位、実際の語、文脈を併せて人が判断してください。
