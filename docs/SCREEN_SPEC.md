# Alphabet Shift Spectrum - 画面仕様書

## 共通

- 初期言語は日本語。切り替え後の言語はブラウザー内へ保存する
- 画面上部右側に日本語／英語の切り替えボタンを置く
- タブは「シフト一覧」「分析」の2つだけを表示する
- 320px／390pxではページ全体を横スクロールさせない
- 広い頻度表とヒートマップは、それぞれの枠内だけを横スクロール可能にする

## ヘッダー

- タイトル：`Alphabet Shift Spectrum`
- サブタイトル：26通りの比較ツールであることを説明
- 限界注記：頻度順位と希少文字チェックは正解を証明しない
- 言語切り替え：日本語時は`English`、英語時は`日本語`

## 入力

- 暗号文テキストエリア
- 有効英字数と20,000文字上限
- 26シフト生成ボタン
- 成功、入力不足、上限超過、入力変更の状態メッセージ

入力を変更すると生成済み結果を消し、再生成を促す。

## シフト一覧タブ

26件のカードをシフト番号順に表示する。各カードは次を持つ。

- `Shift 0`～`Shift 25`
- カイ二乗順位
- 希少文字チェックの「基準内」または「基準超過」
- シフト後の文字列
- A～Z出現回数表

表だけを横スクロール可能にする。J、K、Q、X、Z列は背景色で補助表示する。

## 分析タブ

### 頻度ヒートマップ

- 26行×26列
- 行ラベルは`S0`～`S25`
- 列ラベルはA～Z
- 各セルへ回数を表示
- ポインター時に行・列・セルを強調
- 色だけでなく数値とラベルでも情報を伝える

### 英語文字頻度への適合順位

- カイ二乗値が小さい上位5件
- 順位、シフト番号、χ²値
- 正しい平文を保証しない旨を常時表示

### 希少文字チェック

- 文字数`n`
- 上限頻度`p = 0.00772`
- 5文字全体の`alpha = 0.003`
- 厳密二項上側確率から得た基準`k`
- 基準内と基準超過の2群
- 各シフトの最大回数、合計回数、超過文字
- 教育用モデルの前提と限界を常時表示

## 計算方法モーダル

- `role="dialog"`と`aria-modal="true"`
- 開いたとき閉じるボタンへフォーカス
- Tab／Shift+Tabをモーダル内へ閉じ込める
- Escape、閉じるボタン、背景クリックで閉じる
- 閉じた後は起点のヘルプボタンへフォーカスを戻す

本文は、上限頻度、厳密二項上側確率、5文字のBonferroni補正、読み方と限界を説明する。

## タブ操作

- クリック／タップ
- 左右矢印
- Home／End
- 選択中だけ`tabindex="0"`
- `aria-selected`、`aria-controls`、`aria-labelledby`を同期

## フッター

GitHubリポジトリーへのリンクを表示する。長いリンク文字列はモバイル幅で折り返す。
