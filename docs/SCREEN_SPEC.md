# Alphabet Shift Spectrum - 画面仕様書

## 共通

- 初期言語は日本語。切り替え後の言語はブラウザー内へ保存する
- 画面上部右側に日本語／英語の切り替えボタンを置く
- タブは「シフト一覧」「分析」の2つだけを表示する
- 320px／390pxではページ全体を横スクロールさせない
- 広い頻度表とヒートマップは、それぞれの枠内だけを横スクロール可能にする

## ヘッダー

- タイトル：`Alphabet Shift Spectrum`
- サブタイトル：26通りの比較ツールであることを説明
- 限界注記：頻度順位と希少文字チェックは正解を証明しない
- 言語切り替え：日本語時は`English`、英語時は`日本語`

## 入力

- 暗号文テキストエリア
- カイ二乗順位の参照先を一般英語、均等分布、利用者コーパスから選ぶコントロール
- 利用者コーパス選択時だけ表示するテキストエリアと有効英字数
- 有効英字数と20,000文字上限
- 26シフト生成ボタン
- 成功、入力不足、上限超過、入力変更の状態メッセージ

入力または参照プロファイルを変更すると生成済み結果を消し、再生成を促す。利用者コーパスは各文字へ1件を加える平滑化を行い、本文は保存しない。

## シフト一覧タブ

26件のカードをシフト番号順に表示する。各カードは次を持つ。

- `Shift 0`～`Shift 25`
- カイ二乗順位
- 希少文字チェックの「基準内」または「基準超過」
- シフト後の文字列
- A～Z出現回数表

表だけを横スクロール可能にする。J、K、Q、X、Z列は背景色で補助表示する。

## 分析タブ

### 頻度ヒートマップ

- 26行×26列
- 行ラベルは`S0`～`S25`
- 列ラベルはA～Z
- 各セルへ回数を表示
- ポインター時に行・列・セルを強調
- 色だけでなく数値とラベルでも情報を伝える

### 参照文字頻度への適合順位

- カイ二乗値が小さい上位5件
- 一般英語、均等分布、利用者コーパスのいずれを参照しているか表示
- 順位、シフト番号、χ²値
- 正しい平文を保証しない旨を常時表示
- 入力本文を含めず、文字数、希少文字チェック条件、上位5件、基準内／超過件数、限界をコピー
- クリップボードが拒否された場合は、同じ概要を選択済みの手動コピー欄へ表示

### 分析記録の保存・再読込

- 通常分析と感度ラボの設定が有効な場合だけJSON保存を有効にする
- JSONにはA～Z集計、参照頻度、計算条件、集計結果を含める
- 原文、26通りのシフト文字列、利用者コーパス本文は含めない
- 読み込みは1MBを上限とし、スキーマ、バージョン、数値範囲、度数合計を検証する
- 読み込み後は保存済み順位を信用せず、集計値から上位5件と希少文字結果を再計算して別枠へ表示する
- 現在の暗号文入力や生成結果は読み込みで上書きしない

### 上位3候補のχ²寄与

- χ²順位が上位の3シフトを比較
- 各シフトについて、χ²への寄与が大きい5文字を表示
- 文字、観測回数、期待回数、差、寄与を表示
- 寄与は正解率や誤りの確率ではないと説明

### 閾値感度ラボ

- 通常の希少文字チェックとは独立した学習用試算
- 基準の標本数`n`、上限頻度`p`、全体有意水準`α`、比較数`m`を入力
- Bonferroni補正の有無を切り替え
- 0.5倍、基準、2倍の標本数について、期待値`np`、基準`k`、各比較の`α`、基準値バーを表示
- シフト生成時は基準の標本数を有効英字数へ同期
- 全項目の変更、標準設定への復元、言語切り替えのたびに再描画
- 利用者が入力した`p`や`α`の妥当性、正しい平文、鍵、暗号方式を判定しないと常時表示

### 厳密値とモンテカルロ推定

- 感度ラボの基準行にある`n`、`p`、`k`を使う
- 試行回数は1,000、5,000、20,000から選択する
- 0～4,294,967,295の整数シードを入力する
- 条件、厳密上側確率、推定値、超過回数、絶対誤差を表示する
- 感度条件、試行回数、シード、または生成による標本数が変わったら古い推定を消す
- 単一二項確率だけを扱い、5文字や26シフト全体の誤判定率を推定しないと常時表示

### 希少文字チェック

- 文字数`n`
- 上限頻度`p = 0.00772`
- 5文字全体の`alpha = 0.003`
- 厳密二項上側確率から得た基準`k`
- 基準内と基準超過の2群
- 各シフトの最大回数、合計回数、超過文字
- 教育用モデルの前提と限界を常時表示

## 計算方法モーダル

- `role="dialog"`と`aria-modal="true"`
- 開いたとき閉じるボタンへフォーカス
- Tab／Shift+Tabをモーダル内へ閉じ込める
- Escape、閉じるボタン、背景クリックで閉じる
- 閉じた後は起点のヘルプボタンへフォーカスを戻す

本文は、上限頻度、厳密二項上側確率、5文字のBonferroni補正、読み方と限界を説明する。

## タブ操作

- クリック／タップ
- 左右矢印
- Home／End
- 選択中だけ`tabindex="0"`
- `aria-selected`、`aria-controls`、`aria-labelledby`を同期

## フッター

GitHubリポジトリーへのリンクを表示する。長いリンク文字列はモバイル幅で折り返す。

## レスポンシブ表示

- 320px／390pxでは参照設定、保存操作、モンテカルロ設定、読込結果を1列にする
- 600px以上では保存操作・モンテカルロ設定・読込概要を最大3列にする
- 900px以上では参照プロファイル選択と説明を横へ拡張する
- 頻度表、寄与表、感度表以外でページ全体の横スクロールを発生させない
