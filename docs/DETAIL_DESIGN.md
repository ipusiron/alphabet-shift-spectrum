# Alphabet Shift Spectrum - 詳細設計書

## 目的

入力へ0～25の全アルファベットシフトを適用し、文字列と頻度を比較する教育用ツールである。統計値は手動分析の観察材料として示し、正しい平文、鍵、言語、暗号方式を自動判定しない。

## 対象

- Caesar暗号
- 鍵長1のVigenère暗号
- 同じ26通りのアルファベット回転として扱える教材

## 構成

- Vanilla HTML/CSS/JavaScript
- 外部ライブラリーなし
- HTTP(S)と`file://`の両方で動作
- 日本語／英語切り替え
- モバイルファースト（600px、900pxで拡張）

## ファイル責務

| ファイル | 責務 |
|---|---|
| `index.html` | 意味構造、CSP、静的な翻訳キー |
| `logic.js` | 正規化、シフト、頻度、二項分布、カイ二乗 |
| `messages.js` | 日本語／英語辞書 |
| `script.js` | 状態、描画、操作、アクセシビリティ |
| `style*.css` | 共通、モバイル、タブレット、PCの見た目 |

## 状態

```js
appState = {
  language: 'ja',
  normalizedText: '',
  analyzedRows: [],
  thresholdInfo: null,
  activeTab: 'tab1',
  messageKey: '',
  messageVars: {},
  messageType: 'info'
}
```

入力が生成時点から変わった場合、`normalizedText`、`analyzedRows`、`thresholdInfo`を破棄し、古い結果を表示しない。言語変更時は静的文言とすべての派生結果を再描画する。

## 処理

### 1. 正規化

- 文字列を大文字化
- ASCII英字A～Z以外を除外
- 有効英字は20,000文字まで

### 2. 26シフト

各文字インデックスへ`+shift (mod 26)`を適用する。各結果についてA～Zの出現回数を数える。

### 3. カイ二乗順位

```text
χ² = Σ (observed - expected)² / expected
```

参照英語文字頻度から期待回数を作り、値の昇順で1～26位を付ける。同値の場合はシフト番号の昇順とする。

### 4. 希少文字チェック

J、K、Q、X、Zを対象とし、5文字中で最大の参照頻度`p = 0.00772`を共通の上限として使う。

```text
k = min { k : P(X >= k) <= alpha / 5 }
X ~ Bin(n, p), p = 0.00772, alpha = 0.003
```

二項確率は最頻値を重み1として上下へ漸化式で展開し、総和で正規化する。これにより`(1-p)^n`のアンダーフローを避け、20,000文字まで同じ処理を使う。

1シフト内で5文字を同時に確認するため、Bonferroni補正として各比較へ`alpha/5`を用いる。いずれかの文字数が`k`以上なら「基準超過・要確認」とする。これは候補の除外や正解判定ではない。

### 5. ヒートマップ

26行×26列の出現回数を、全セル中の最大値に対する相対比で5段階表示する。各セルには数値とアクセシブルなラベルを併記する。横幅が狭い画面ではヒートマップ内部だけを横スクロールさせる。

## セキュリティ

- 動的文字列は`textContent`で描画
- CSPは自己ホストしたスクリプト／スタイルだけを許可
- 外部通信、外部依存、動的コード評価なし
- 入力長を20,000有効英字へ制限

## テスト

- 正規化、正負のシフト、頻度、26行生成
- 厳密二項上側確率と直接和の一致
- 基準値の最小性、境界値、標準偏差、多重比較補正
- カイ二乗順位、グループ分割、最大入力
- CSP、タブ数、スクリプト順序、日英辞書、再描画契約、README英語版
